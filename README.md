# PhishShield: Conversational Phishing Detection & Awareness Assistant

PhishShield is a conversational cybersecurity assistant developed using Microsoft Copilot Studio. Built as a rapid prototype for a company innovation Bot-a-thon, the bot evaluates suspicious text-based communications (emails and messages) to provide real-world risk classification and actionable user guidance.

---

## The Paradigm: Conceptual Design & AI Automation
Because this project was developed in a low-code environment, traditional software engineering files are absent. Instead, this repository showcases the **conceptual engineering, architectural planning, and formulaic logic** that powered the tool. 

* **My Role:** Led the end-to-end design, established the logic rules, resolved structural variable errors, and managed the topic execution pathways.
* **AI/Low-Code Layer:** Microsoft Copilot Studio translated these logic hierarchies into a live conversational engine.

---

## Key Features
* **Dual Analysis Modes:** Custom handling for both raw emails and SMS/chat messages.
* **Hierarchical Risk Classification:** Categorizes threats safely into *High Risk*, *Medium Risk*, or *Safe*.
* **Explainable Logic Engine:** Normalizes inputs and surfaces exactly why a message triggered an alert.
* **Dual-Purpose Tooling:** Acts simultaneously as a frontline triage assistant and an educational training module.

---

## Project Outcomes
* **Reliable Routing:** Successfully trapped common social engineering cues (urgency, link masking, financial validation traps).
* **Rapid Prototyping Proof:** Demonstrated how security teams can use conversational AI environments to deploy functional awareness tools within organizational silos swiftly.
